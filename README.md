# 啖呵売！昭和人情商店街

> 売って笑わせ、失敗して、最後は人情。

旅商人「風間まこと」となって露店で口上を切り、騒動を起こしたり収めたりしながら商売する、ブラウザで遊べる会話選択型ドタバタ喜劇です。昭和の露店商売と人情喜劇から着想を得たオリジナル作品で、登場人物・台詞・商店街はすべて創作です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（サーバー・ビルド・ログイン不要、PC／スマホ対応）。

- 全五幕。各幕に客や騒動が現れ、3つの口上から1つを選びます（数字キー 1〜3 でも選択可）。
- 口上の型：**大風呂敷**／**機転**／**正直**／**お世辞**／**お助け**
- 客ごとに好む口上・嫌う口上があり、相性で効果が変わります（好む：売上1.5倍＋笑い・人情ボーナス、嫌う：売上半分＋騒動）。
- 大風呂敷を2回続けると「調子に乗りすぎ」で騒動が上乗せされます。
- **勢い**：笑いを取るとたまり（最大3）、大風呂敷の売上が「勢い×35%」伸びます。満タンで大風呂敷を切ると大騒動（騒動+15、勢いは0に）。正直・お助けに切り替えると「勢い×400円」を上乗せして勢いを手放します。
- **仕入れ**：開店前に予算3,000円で品を3つまで選ぶ。品ごとに効く口上・相手・幕が違う（七色ハッカ飴＝大風呂敷の売上+20%、なんでも開けるくん＝機転の売上+25%、福招き猫＝正直・お助けの人情+4、万能ねじ回し＝職人・巡査相手の売上+40%、和紙のうちわ＝最後の幕の売上+30%、おもちゃの笛＝子ども・小春相手の笑い+6・人情+2）。選んだ品は次回も覚えておく。
- **旅に出る**：タイトル画面の「旅に出る（3つの町）」で町一覧が開き、10 の町から 3 つを回る。最初は日和町商店街、次からは道でつながった町を選ぶ（下の道の図）。Android 版では、つながっていない町もリワード広告を見れば旅に 1 回だけ鍵を開けて行ける。町ごとに仕入れ直して5幕の商売をし、人情（評判）の半分と縁を次の町へ持ち越す。前の町で見た場面は出ない。最後に旅全体の結末（5種：旅の大団円・騒動の渡り鳥・人情の旅路・名物旅商人・また次の旅へ）が決まる。商売した町は「町めぐり」に記録され（町ごとの最高売上つき）、10 の町すべてで商売すると「全町制覇」。日和町以外の 9 つの町には、それぞれ 5 つの町の場面と 2 人の町の人がいる。
  - 道：日和町商店街 ─ 潮見港・湯ノ沢温泉・峠ノ茶屋宿・鶴見城下町／潮見港 ─ 凪島・黒岩炭坑町／湯ノ沢温泉 ─ 雪見町の朝市・光明寺門前町／峠ノ茶屋宿 ─ 黒岩炭坑町・雪見町の朝市／鶴見城下町 ─ 光明寺門前町・青葉台学生街
- **常連帳**：人物メモは最初はぼかしてあり、好きな口上・苦手な口上は分かりません。相性◎や×が出ると常連帳に書き込まれ、次から選択肢に「◎ 好み」「× 苦手」の印が付きます（記録画面でも確認できます）。
- **縁**：口上の選択で縁が結ばれ、あとの幕に続きのイベントや効果が出ます（さよりの恩返し・苦情、銀二の助け舟・仕返し、健太の母親、源造の軒先）。最近のプレイで見た場面は出にくくなります。
- 売上・笑い・人情・騒動のバランスで、全5種の結末に分岐します。

## ファイル構成

```
index.html          画面構造（タイトル／商売／結果、遊び方・記録ダイアログ）
styles.css          昭和紙芝居風デザイン（色・フォントは :root の CSS 変数に集約）
logic.js            ゲームロジック（DOM非依存・Node でもテスト可能）
portrait.js         人物の立ち絵（SVG、4種の表情差分）を生成
audio.js            音楽・効果音（Web Audio API でその場で合成）
game.js             画面制御・演出・localStorage への記録・Android 向けの処理
i18n.js             表示言語（日本語 / 英語）の切り替えと画面の文言
ads.js              Google AdMob 広告（Android アプリのみ）
ads-config.js       広告のモード（test / production。ビルド時に生成し直す）
build-info.js       タイトル画面に出すバージョン（ビルド時に生成し直す）
icon.svg            Web 版のアイコン（assets/ に Android 用のアイコン・起動画面の元画像）
data/characters.js  登場人物（性格・相性・外見）
data/events.js      イベント10種（発生条件・会話・選択肢・効果量）
data/endings.js     エンディング5種（判定順・条件・称号）
data/en.js          人物・イベント・結末の英訳（同じ ID で対応）
tests/              ロジックの自動テスト
android/            Android アプリのプロジェクト（Capacitor）
scripts/            Android に同梱する Web ファイルを www/ にまとめるスクリプト
```

シナリオを増やすときは `data/` 内のファイルにデータを追加するだけで、ゲーム本体の変更は不要です。データは文章と数値のみで、コードとして実行されることはありません。

## 仕様の要点

| 項目 | 内容 |
| --- | --- |
| 初期値 | 売上0円・笑い10・人情30・騒動0・客数0 |
| 値の範囲 | 笑い・人情・騒動は0〜100、売上は0円未満にならない |
| 進行 | 全5幕。3幕目は中規模イベント、5幕目は最終イベントを優先して出題。同じイベントは1プレイで重複しない |

| 客数 | 売上が出たら+1人、笑い15以上を取ったら見物人が集まり+2人 |
| 保存 | 最高売上・到達した結末・プレイ回数・最後の称号（保存できない環境でもゲームは続行） |

## 英語対応

日本語と英語で遊べます。端末の言語が日本語なら日本語、それ以外は英語で始まり、タイトル画面の「日本語 / English」で切り替えられます（選んだ言語は保存されます）。

- 画面の文言は `i18n.js`、人物・イベント・結末の文章は `data/en.js` にあります。英訳がない項目は日本語のまま表示されます
- 英語版のタイトルは「Tankabai! Showa Shopping Street」、通貨は「¥1,500」の形式です
- シェア文も表示中の言語で作ります（英語のハッシュタグは「#Tankabai」）。プライバシーポリシーは英語版のページ（https://techgym.jp/privacy-policy-en/）を開きます
- Android の端末が英語のときは、ホーム画面のアプリ名も「Tankabai!」になります
- テストで、日英の文言のキーがそろっていること、すべての人物・イベント・選択肢・結末に英訳があること、英訳に日本語が残っていないことを確かめています

## 結果のシェア

結果画面の「結果をシェアする」から、X・Facebook・LINE への投稿と URL のコピーができます。スマホなど Web Share API に対応した端末では「シェア」ボタンも表示され、端末の共有メニューを開きます。

- シェアする URL：https://techgym.jp/column/claude-code-game-tankabai/ （`game.js` の `SHARE_URL`）
- 投稿文：たどり着いた結末・称号・売上（例：『啖呵売！昭和人情商店街』で結末「笑いの名人」にたどり着いた！称号は「笑わせ上手」、売上7,250円。）
- X ではハッシュタグ「#啖呵売昭和人情商店街」を付けます（`SHARE_HASHTAG`）。Facebook は仕様上、URL のみを共有します。

## 音楽・効果音

音声ファイルは使わず、`audio.js` がブラウザ内で三味線風の撥音・太鼓・拍子木・鈴などを合成して鳴らします。旋律はヨナ抜き音階によるオリジナルです。

| 場面 | 音 |
| --- | --- |
| タイトル・商売中 | にぎやかな商店街の BGM（騒動70以上でテンポが上がる） |
| 商売開始 | 太鼓三つ＋拍子木 |
| 大ウケ・毎度あり | 拍子木＋駆け上がる三味線 |
| 人情 | 鈴の音 |
| 大失敗・調子に乗りすぎ | 太鼓＋すべり落ちる音 |
| 売上 | 小銭の音 |
| 次の幕へ | 拍子木「チョン、チョン」 |
| 結末 | だんだん速くなる拍子木で幕引き、しみじみした BGM |

- ブラウザの自動再生制限に従い、最初のクリックやキー入力から鳴り始めます。
- タイトル画面で「音楽」「効果音」を個別に、商売中は右上の 🔊 ボタンでまとめて消せます（設定は保存されます）。
- タブを切り替えている間は音を止めます。Web Audio に対応しないブラウザでは、音なしでそのまま遊べます。

- 結果は色だけでなく文字・記号（▲▼、スタンプ文字）でも表示

## Android 版（Google Play 配布用）

[Capacitor](https://capacitorjs.com/) 8 でゲームのファイルをアプリ内に同梱しているため、ネットにつながっていなくても遊べます。

- 縦画面固定・全画面表示（システムバーを隠す）、プレイ中は画面が暗くならない
- Android の戻るボタン：ダイアログを閉じる／商売中は確認してタイトルへ／タイトル・結果画面ではアプリを終了
- 別のアプリに切り替えると音が止まる
- 「📤 シェア」は Android の共有メニューから LINE や X などを選べる
- 数字キーの案内は出さない
- タイトル画面にビルド番号・プライバシーポリシー・（EU など必要な地域だけ）「広告の設定」を表示

アプリ ID（パッケージ名）は `jp.techgym.torasan` です（Google Play に一度公開すると変更できません）。

### 広告（Google AdMob）

Android アプリでのみ広告を表示します（Web 版には広告は出ません）。

| 広告 | タイミング |
| --- | --- |
| インタースティシャル（全画面） | 仕入れ画面で開店するとき（タイトル画面の「商売を始める」・結果画面の「もう一度商売する」のあと、毎回）、遊び方・記録を閉じてタイトル画面に戻るとき、商売の途中で戻るボタンからタイトル画面に戻るとき、結果画面の「タイトルへ」を押したとき、毎回（読み込めていなければ出さずに進む） |
| リワード | 「大失敗！」「調子に乗りすぎ！」「大騒ぎ！」が出た直後の「📺 広告を見て口上を言い直す」。最後まで見ると、その幕の口上を選び直せる（どの幕でも、1 プレイ 1 回） |
| リワード（旅） | 旅の町一覧で、鍵のかかった町の「📺 広告を見て鍵を開ける」。最後まで見ると、その町が旅の行き先に選べるようになる（旅 1 回につき 1 回） |
| バナー | すべての画面の下に出しっぱなし（商売中も）。バナーの高さだけ画面の下に余白を空け、ボタンが広告に隠れないようにする |

起動時に Google の同意確認（UMP）を行い、確認でエラーになっても広告は出せるようにしています。広告は先読みし、失敗したら 20 秒後に再挑戦、表示時に未読み込みなら最大 8 秒待ちます。

動作確認用の APK は Google 公式のテスト広告を表示します。Google Play 用の AAB だけが本番の広告になります（`ADMOB_MODE=production npm run build`）。

本番の AdMob ID は次の 2 か所にあります。Google Play 用にビルドするとき、ID が欠けていたり桁数がおかしかったりすると、ビルドが止まります。

| 場所 | 値 |
| --- | --- |
| `android/app/src/main/res/values/strings.xml` の `admob_app_id` | アプリ ID |
| `ads.js` の `UNITS.production` | インタースティシャル・リワード・バナーの広告ユニット ID |

### Google Play へ公開する手順

1. AdMob でアプリ（Android・ストア未掲載）を追加し、インタースティシャルとリワードの広告ユニットを作成して、上の 2 か所に ID を入れる。「プライバシーとメッセージ」→「欧州の規制」のメッセージに、このアプリを対象として追加する
2. リポジトリの Settings → Secrets and variables → Actions に、アップロード鍵の 4 つを登録する
   （`ANDROID_KEYSTORE_BASE64` / `ANDROID_KEYSTORE_PASSWORD` / `ANDROID_KEY_ALIAS` / `ANDROID_KEY_PASSWORD`）
3. Actions の「Android build」を実行すると、署名済みの `torasan-release-aab`（.aab）ができる
4. [Google Play Console](https://play.google.com/console) でアプリを作成し、.aab をアップロードする
   （ストア掲載情報・スクリーンショット・プライバシーポリシー https://techgym.jp/privacy-policy/ ・コンテンツのレーティング・広告を含む・広告 ID の申告・データセーフティ・ターゲットユーザー 13 歳以上などの入力が必要です）
5. 公開後、AdMob でアプリを Google Play のストアに紐づける

アップロード鍵とパスワードは、チャットやリポジトリで共有しないでください。本番の広告を自分でタップしないでください（動作確認は Release の APK で行う）。
