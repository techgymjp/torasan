# 啖呵売！昭和人情商店街

> 売って笑わせ、失敗して、最後は人情。

旅商人「風間まこと」となって露店で口上を切り、騒動を起こしたり収めたりしながら商売する、ブラウザで遊べる会話選択型ドタバタ喜劇です。昭和の露店商売と人情喜劇から着想を得たオリジナル作品で、登場人物・台詞・商店街はすべて創作です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（サーバー・ビルド・ログイン不要、PC／スマホ対応）。

- 全五幕。各幕に客や騒動が現れ、3つの口上から1つを選びます（数字キー 1〜3 でも選択可）。
- 口上の型：**大風呂敷**／**機転**／**正直**／**お世辞**／**お助け**
- 客ごとに好む口上・嫌う口上があり、相性で効果が変わります（好む：売上1.5倍＋笑い・人情ボーナス、嫌う：売上半分＋騒動）。
- 大風呂敷を2回続けると「調子に乗りすぎ」で騒動が上乗せされます。
- 売上・笑い・人情・騒動のバランスで、全6種の結末に分岐します。

## ファイル構成

```
index.html          画面構造（タイトル／商売／結果、遊び方・記録ダイアログ）
styles.css          昭和紙芝居風デザイン（色・フォントは :root の CSS 変数に集約）
logic.js            ゲームロジック（DOM非依存・Node でもテスト可能）
portrait.js         人物の立ち絵（SVG、4種の表情差分）を生成
game.js             画面制御・演出・localStorage への記録
data/characters.js  登場人物（性格・相性・外見）
data/events.js      イベント10種（発生条件・会話・選択肢・効果量）
data/endings.js     エンディング6種（判定順・条件・称号）
tests/              ロジックの自動テスト
```

シナリオを増やすときは `data/` 内のファイルにデータを追加するだけで、ゲーム本体の変更は不要です。データは文章と数値のみで、コードとして実行されることはありません。

## 仕様の要点

| 項目 | 内容 |
| --- | --- |
| 初期値 | 売上0円・笑い10・人情30・騒動0・客数0 |
| 値の範囲 | 笑い・人情・騒動は0〜100、売上は0円未満にならない |
| 進行 | 全5幕。3幕目は中規模イベント、5幕目は最終イベントを優先して出題。同じイベントは1プレイで重複しない |
| 発生条件 | 例：「おかみさんの叱責」は騒動15以上のときだけ発生 |
| 客数 | 売上が出たら+1人、笑い15以上を取ったら見物人が集まり+2人 |
| 保存 | 最高売上・到達した結末・プレイ回数・最後の称号（保存できない環境でもゲームは続行） |

### エンディング判定（上から順に判定）

| 順 | 条件 | 結末 |
| --- | --- | --- |
| 1 | 騒動55以上 かつ 人情45以上 | 大騒動の末の人情 |
| 2 | 騒動85以上 | 商店街大騒動 |
| 3 | 人情75以上 | 人情の旅人 |
| 4 | 売上8,000円以上 かつ 笑い60以上 | 露店の大繁盛 |
| 5 | 笑い70以上 | 笑いの名人 |
| 6 | 上記以外 | また明日、旅の空 |

「大騒動の末の人情」は、全組み合わせを探索した結果、5幕の中で騒動85と人情の高値は両立しないため、救済ルートとして騒動55・人情45に調整しています。

## アクセシビリティ

- 結果は色だけでなく文字・記号（▲▼、スタンプ文字）でも表示
- キーボード操作（Tab／Enter、数字キーで口上選択）、結果の読み上げ用ライブリージョン
- OS の「視差効果を減らす」設定、またはタイトル画面の「演出を控えめにする」で集中線・揺れなどを抑制

## テスト

```sh
npm test
```

Node.js 18 以上の標準テストランナーで、データ定義、5幕進行、値の範囲、不正操作の無視、相性補正、エンディング判定、全6結末への到達可能性を検証します。
